# 备用探索的候选接纳 × 停止条件消融

2026-09-13；本轮新增处理在运行前固定。用户的“下一步”授权继续拆分上轮发现的机制问题。目录为本轮新增产物；原 F/S、旧结论与旧正文不覆盖。

## 问题与证据身份

上一轮两种全局 Top10 阈值重启绝大多数分路没有新增基图物理评分，F 相比它们仍有额外救回，但候选接纳与停止方式同时变化。本轮在同一局部队列框架内分开两个因素，并加入没有距离提前停止的简单重启。

使用已暴露的最终 7999 查询和 seed42/777/1234 三张既有 T2I Lucene9.12.0 原生 COSINE200 图与 graph-specific Top50 GT。Recall@10 仅用 GT 前十项。此为假设驱动、预先固定处理的回顾性机制扩展，不是新的独立确认，也不声称原始 raw-IP T2I 榜单结果。不得选取新增正例、删去不利查询或根据结果改变处理。

## 2×3 因素

每条 scout 开始时均建立新的宽10局部评分门槛；它与全局返回 Top10 分开。全部动作共用评分缓存、BASE/OPEN/COMPLETED、邻接游标及全局返回结果。只改变以下两项。

候选接纳：

- L：按 F 原定义，首次 BASE 发现的邻居分数严格大于发现前的局部第十分数，才加入 active；其余进入 deferred。接纳时维护局部门槛。
- A：所有首次 BASE 发现的邻居进入 active，并维护局部 Top10。低于该 Top10 的插入不改变门槛。没有候选截断。

停止条件（都先完成已打开节点的邻接游标，受硬评分 cap 约束）：

- LOCAL：active 最优分数严格低于新建的局部第十分数即停；与原 F 的比较运算一致。
- GLOBAL：全局输出已满10项时，active 最优分数严格低于全局第十分数即停；对应上一轮 R_LOCAL 的距离停止语义。
- NONE：无分数距离提前停止；仍受当前路额度及候选可用性约束。L_NONE 不把未接纳的 deferred 自动变成 active，否则会同时取消接纳因素。

每次选择候选前，L 仅恢复高于当前局部门槛的 deferred（沿用原 F）；A 恢复全部 deferred。删除已 COMPLETED 的 active 顶项；队列为空时区分仍有 deferred 与全部耗尽。NONE 因队列耗尽可能未花满额度，不能预设所有分路都一定推进400次。

完整新增七臂：C、L_LOCAL、L_GLOBAL、L_NONE、A_LOCAL、A_GLOBAL、A_NONE，共7999×3×7=167979条效果记录。L_LOCAL 必须复现冻结 F，A_GLOBAL 必须复现上一轮 R_LOCAL，C 必须复现冻结 C；S 只作旧参考。

接纳的严格 > 与停止的严格 < 有不同的同分值语义。记录并保留这些边界；不得为了让某两组相同而事后统一比较运算。

## 共同搜索与成本

共同 primary 完整调用冻结 OnlineSelection.Run.primary，cap6400、gamma=.075、原上层下降，实际评分为p。每臂最终cap=p+6400≤12800。每个备用动作四次最多400新增实际评分，包含上层下降；未用额度留给最终主路 distanceAdvance(+∞)。保留原主路未完成 current 和游标；不启用共享主队列重排。

入口使用冻结64项 upper-entry表，始终取首个未标ENTRY或BASE的项。每臂第一次入口身份相同；干预后的BASE状态可以使后续实际入口/落点分歧，这是处理的后续效应，不能声称逐路入口强制相同。保留入口、落点及其工作量。

上层下降后标ENTRY，清空局部门槛，按原 seed 规则避免重新 BASE 访问。每路结束时，把 active/deferred/未完成current按原 F 的规则并入主路，不重建全局门槛。最后原 distanceAdvance(+∞) 续搜。A_GLOBAL 虽有统一的局部门槛维护，但其队列/停止与最终续搜不读取该局部门槛；工程检查与全量回归必须确认旧 R_LOCAL 的结果和实际路径未改变。

记录实际 native评分、logical、读边、完成展开；每路实际评分/上层评分/基图展开/候选接纳与延后/停止原因，以及primary、各路后、post-scout、最终Top10。记录完整路径对 C/F 的LCP、评分集合Jaccard和序列摘要。每个新臂的完整 primary 物理评分前缀必须与 C 相同。固定真实工程案例保存完整 ordinal/score-bit 轨迹。

总cap相同不是实际成本相同，分析必须逐事件对账。每路评分分配可随接纳/停止因素变化，它是机制的一部分；本轮不将结果解释为“固定相同实际scout评分下”的直接效应，也不把四路之后的差异单独归因于第一路。

本轮无正式计时。诊断记录耗时只用于进度；不从读边、序列或运行秒数推断端到端速度。

## 预先指定分析

1. 六个格子的Recall@10、严重(<0.5)、零命中、救回/伤害、评分和读边，以及三个图分别的结果。C/F/S为可识别参考，不重新调S。
2. 同一停止条件下A相对L的三组接纳效应；同一接纳条件下LOCAL相对GLOBAL、NONE相对GLOBAL、NONE相对LOCAL的六组停止效应；额外呈现F相对A_NONE及各因子格子相对C。
3. 按qid聚合三个图、PCG64 seed2026091302、20000次percentile查询簇bootstrap，对严重发生率差提供描述性95%区间。主表同时报告实际救回与伤害，所有比较完整保留，不作多重比较后的确证性胜出或最优策略选择。预定差分中的差分为[(L_LOCAL相对L_GLOBAL的严重减少)−(A_LOCAL相对A_GLOBAL的严重减少)]，另给NONE对应交互；这是当前具体处理的有限总体差异，不是通用定理。
4. 同一格子的post-scout到最终命中增量，F与其他格子在同一阶段的命中身份/后续发现差异，以及分路终止分布。描述相同返回但不同路径；不从相似度直接推出因果。
5. 检查A_NONE是否实际推进基图并获得不同结果。它是允许充分探索的简单重启控制，仍不代表整个NSW家族最优，也不是NSW原系统复现。
