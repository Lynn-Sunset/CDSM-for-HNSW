# 三组判别实验：冻结协议

本轮执行研究重审中的强基线、共同状态干预、WebVid 简单结构补救。数据和索引输出均在 D 盘。既有实验不覆盖。

## 数据与隔离

- T2I：现有 1M 原始底库，按历史 Java 运算顺序单位化，COSINE 搜索与原生 exact Top50。开发 q0–499；确认集拟用 q90000–91999，先审计可用历史命令与字节重复；若有既往搜索覆盖或重复，按行号向后取足 2000 条未使用唯一查询，并先保存 ID 清单。测试结果不用于挑阈值或配置。
- 三张新原生 Lucene 9.12 图，M16、efConstruction100，构图种子 42/777/1234。固定原始插入顺序、单线程写入与串行合并；它们检验层级／构图随机性，不代表插入顺序鲁棒性。输出实际图邻接哈希，不能只以索引文件哈希不同证明种子生效。
- WebVid：现有 40K 底库；原图作旧案例对照，另建相同三个种子的图。开发使用旧查询前500条；新确认查询为跳过此前2000条唯一 caption 后的下2000条唯一 caption，使用同一缓存模型编码，先冻结文本和 ID。它仍是配对 caption 的自定义查询，不宣称外部独立官方测试。
- 先完成工程验证和开发选择，再冻结主比较配置，之后打开确认集。确认结果包括全部方法，查询和图的不确定性分别解释。

## E1：强单路基线

候选族：原生 collector 宽度调优、同一 persistent 实现的宽度对照、ungated、DABS 距离停止、固定单 scout、冻结低分触发单 scout、四 scout。原生 scorer 的每次实际调用收费，缓存命中不重复收费；特征、候选筛选和推理时间均属于在线开销。

原生和匹配实现宽度网格 10/50/100/200/350/500/700/1000/1600/2400；DABS gamma 网格 0/.005/.01/.02/.04/.08/.16/.32。对 cosine 使用单位球弦距离，s=(1+cos)/2，d=2*sqrt(1-s)。停止判据为 d(candidate)>=(1+gamma)*d(kth)，不能把 similarity 减固定常数冒充 DABS。保留所有待展开节点；有限 cap 不继承无界理论保证。采用同一HNSW上层下降，明确这是停止规则的本地适配，不冒称完整复现作者代码。

宽度/DABS 曲线设置最大 cap=25600；额外入口策略和 ungated 比较 cap=1600/3200/6400/12800/25600。四 scout 每路额度 cap/16；单 scout（含4个候选评分）总额度 cap/16，保留6400时400的原设置；主宽度1600。低分阈值沿用训练冻结值0.733723402，入口位置1，不重新学习。

主效率终点：每图每族在开发集选择平均 recall>=0.98 时平均 dc 最小的配置，然后测确认集达到的召回、dc、时间；达不到目标必须如实报告，不替换成测试赢家。0.95为次要目标。开发集运行完整曲线，确认集只运行预选配置及预定6400参考，减少无必要的确认集多重比较；目标约束比较不冒称测试召回精确匹配。

计时在建图、exact 和效果评测均结束后串行进行。每方法至少100次预热，确认集中固定前300条，5次随机交错测量；重复的相同策略作为噪声对照。加载、CSV写入不计时；scorer创建、候选决策和输出计时。复制多分支状态的诊断成本不混入单次在线计时。

## E2：共同状态干预

T2I同一确认集、三张新图，每条查询共同的宽度10/probe400状态复制后分支，总cap6400：

1. 继续原宽度10，保留原规则。
2. 只放松停止但保留后续接纳门控（区分 break 与 admission）。
3. 放开接纳/停止，但丢弃 probe 的 deferred 队列，仅恢复既有前沿。
4. 完整放开接纳/停止并恢复 deferred 候选。
5. 放宽到1600，包括 deferred 可再接纳。
6. 固定单个 upper-table 入口，400额度后继续main1600。
7. 每查询预先确定的随机 base 入口，400额度后继续main1600。
8. 原四 scout，各400额度后继续main1600。

复制候选、visited/completed、分数、deferred、邻接游标及计数；不从空状态重启充当续搜。记录每目标首次命中dc、候选GT集合增减、评分序列和实际用量。与完整恢复和main1600分别配对，预先保留全部八种动作的比较族。离线GT只用于结果／诊断，不能进入动作选择。

## E3：WebVid 最小结构补救

按图导出L0有向邻接，计算强连通分量、源/汇分量、零入度点和最大分量以外的节点。所有辅助结构仅由图生成，不能根据测试GT定制。

比较：ungated、main1600、四scout、扫描最大SCC外全部节点后继续、为每个源SCC增加一个确定代表入口、相同数量随机节点扫描、SCC连接修复后ungated。修复边为最大SCC代表到其他源代表，以及其他汇代表到最大SCC代表；验证修复后的L0强连通性。代表为最小ordinal，无向量搜索或测试查询参与选择。记录预处理时间、辅助节点/边、查询额外评分与实际收益。有限预算搜索仍无100%召回保证。

开发预算曲线400/800/1600/3200/6400/12800，确认集主比较6400，不根据开发结果改变补救算法。确认集使用新2000查询；旧q1272/doc8598只用于验证原机制和补救，不参与新样本推断。

## 验证与统计

预算/真实scorer调用一致；native调用次数核验；共同状态复制、分段续搜和取消门控的序列一致；新实现与已有v3在开发样本的结果和路径核验。DABS使用独立、直接距离判据的慢参考实现比对。图重建检查所有节点ID、层级和邻接摘要。每套真值抽样用独立NumPy float64精确Top50核对，记录ties／打分差异而不隐藏。

召回按query配对bootstrap10000次。三图先按同一qid取均值作为主要查询重采样输入，同时报告每图结果和范围；不把6000条图×查询记录当6000独立查询。少量图不足以精确估计任意构图总体。多动作使用同时区间；计时按qid聚类，报告相同策略重复的噪声幅度。

冻结代码、输入、查询ID和开发选择哈希。失败中间产物保留；修复后用新attempt目录，禁止覆盖已经完成的确认结果。调整协议必须在确认运行前记录理由。
